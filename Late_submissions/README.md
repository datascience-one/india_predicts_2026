# Late Submissions

This folder contains participant submissions that were received **after the official deadline** for the India Predicts 2026 Election Prediction Competition.

These submissions are shared here for completeness and transparency.

## Notes

- Late submissions may **not be considered for official evaluation or rankings**, as per the competition guidelines.
- All files are provided as received, without any modifications.

For more details about the competition, please refer to the main repository README.
