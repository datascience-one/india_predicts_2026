# On-Time Submissions

This folder contains all participant submissions that were received **on or before 30 April 2026** for the India Predicts 2026 Election Prediction Competition. A total of 31 participants had submitted before the official deadline. 

Each submission is provided as received from the participant, without any modifications.

## Notes

- All files in this folder are considered **valid entries** for evaluation.
- Submissions have been organized individually for transparency and ease of access.
- Evaluation and results will be based only on submissions received within the deadline.

For details about the competition, guidelines, and evaluation process, please refer to the main repository README.
