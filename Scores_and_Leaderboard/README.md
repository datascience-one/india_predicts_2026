# India Predicts 2026 – Results & Scores

This folder contains the final evaluated results and prediction analysis for the **India Predicts 2026** Election Prediction Competition conducted by [Data Science Academy](www.datascience.one).

## Files Included

### Leaderboard (Final) - IndiaPredicts2026.xlsx

The Excel workbook included in this folder contains the following sheets:

#### **Leaderboard Final**
Contains the final participant rankings based on prediction performance.

Participants are ranked primarily by *overall prediction accuracy metrics*

This sheet provides a consolidated leaderboard view of participant performance across the competition.

---

#### **Master Predictions Data**
A detailed long-format dataset containing one row per Candidate × Participant prediction

This sheet contains approximately **231,000 rows** of prediction data and is intended for deeper analysis and filtering.

The dataset can be filtered/analyzed using fields such as:

- State
- Participant
- Constituency
- Party
- Coalition
- Predicted Outcome
- Actual Outcome

This sheet is especially useful for participants, analysts, and researchers interested in comparative electoral forecasting analysis.

---

#### **Notes & Legend**
Contains:

- Description for each sheet
- Coalition / alliance legend used in the workbook

The coalition mapping references publicly available information sourced from Wikipedia.

---

## Notes

- Only valid submissions received before the deadline were included for official evaluation.
- Late submissions were excluded from leaderboard calculations.
- All evaluations were performed programmatically using the officially published election results.

For more details about the competition and participant submissions, please refer to the main repository README.
